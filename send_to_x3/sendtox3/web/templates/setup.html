Or copy it to the SD card

Download SD-card plugin bundle (zip)

  1. Unzip it at the top level of the X3's SD card. It contains the hidden folder .crosspoint/plugins/sendtox3 and an {{ opts.inbox_folder }} folder. On a Mac, Finder hides folders starting with a dot; use unzip -o sendtox3-sd-card.zip -d /Volumes/<card> in Terminal.
  2. On the X3 turn on Settings > Connectivity > Plugins (it is off by default).
  3. Open Home > Plugins > Send to X3. Until you share something, its only row is Nothing new right now; afterwards the first row, Get 1 new, downloads it.

The bundle contains this server's address and the device token. Download it again if either changes.

iPhone and iPad: share sheet shortcut

{{ ios_shortcut_note }}

{% if qr %} {% endif %}
Address{{ ingest_url or "(unknown)" }}
HeaderAuthorization: Bearer <ingest token>

To build the shortcut yourself in the Shortcuts app:

  1. New shortcut. In its details turn on Show in Share Sheet and accept Text, URLs, Safari web pages and Rich text.
  2. Add Get Contents of URL with the address above, method POST, a header Authorization with the value Bearer, a space and the ingest token, and a JSON request body with a text field text set to Shortcut Input.
  3. Add Get Dictionary Value for the key message, then Show Notification with that value.

This works on your home Wi-Fi. Away from home, send an email instead (below).

Android, computers and scripts

On Android, install HTTP Shortcuts, then import this file (menu > Import / Export > Import from File). It already contains this server's address and the ingest token, so keep it private.

Download HTTP Shortcuts file

Any app that can send an HTTP request works too (method POST, the address above, the Authorization header, a form body with a field text holding the shared text).

curl -H "Authorization: Bearer <ingest token>" --data-urlencode "text=https://example.com/article" {{ ingest_url or "http://:" ~ opts.port ~ "/api/v1/ingest" }}

Fields: url, text, title, html, kind (auto, url, text, html), or a file part named file (PDF, TXT, HTML, EPUB).
